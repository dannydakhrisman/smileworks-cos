# Output

Every deliverable lives here. One folder per piece of work.

**Folder name:** `yyyymmdd-category-title`
- `yyyymmdd`: date the folder was created (it never changes)
- `category`: research · content · design · ops · comms · strategy · review
- `title`: short kebab-case title

**Rules**
- Updates and recurring runs stay in the same folder. Never create a new folder for an update.
- Each folder has a `README.md` with the request, the assigned agent(s), the status and a change log.
- Agents write only in the folder the Chief of Staff assigned to them.

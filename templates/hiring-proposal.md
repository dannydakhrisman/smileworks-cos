# Hiring proposal: `category-specifictask`

- **Gap:** what task came in and why no current agent fits
- **Mission:** one sentence, one job
- **Inputs / Output / Done when / Must not:** the full job description
- **Uses:** existing skills, connectors or tools it relies on
- **Reviewer:** which agent checks its work, or whether one must be hired too
- **Frequency:** one-off or recurring (and the schedule)
- **Cost:** rough token and time cost per run
- **Recommendation:** Hire / Don't hire (Chief of Staff handles it) / Extend an existing agent
- **Decision needed:** Approve / Reject / Change
